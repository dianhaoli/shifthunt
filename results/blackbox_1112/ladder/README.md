# Method ladder on the shipped six, before and after the scan fix (plan 0b.1, 0b.2)

Generated by `scripts/method_ladder.py --compare-readme six,six_legacy,six_both` from `ladder_summary_six.json` (fixed scan) and `ladder_summary_six_legacy.json` (legacy scan, `--legacy-scan`); 6 episodes, 200 seeds for the seeded verify rungs. Commands: `COMMANDS.md`.

**These are PRIVILEGED scripted ceilings, not agent-equivalent baselines.** Every rung reads the generator's own property list and the episode's label-aligned property set from the private `answer.json`, the private paired scan (each property flipped in isolation on 32 stored base notes, with SAE latents and true probe logits; on free-text episodes the conditional property is split out from its parent), and submits the generator's exact detector regex for whatever it claims. An agent gets none of that: it has to propose the property, write the edit and the regex itself. A rung passing means "solvable once the right property is on the candidate list", not "cheap for an agent". The verify rungs read each candidate on 1-3 stored bases (verify_4/8/8g/16w/24w: one base per reading, verify_16: two, verify_24: three; verify_inf: all valid bases), and single-base readings are noisy.

The fix: a nested child property's flips are read only on the scan bases where its parent is present (on the other bases the pair is a textual no-op, which halved the child's ratios). It changes latent ratios, true ratios, the mean latent shift used to pick latents, and the base draw of the verify rungs. Templated episodes have no nested property and are bit-identical (`sub` = tmpl rows: before = after).

Outcomes: **full** = the rung's submission passes every slot (naming + removal + kept, all-or-nothing per episode; the October outcome). **NAME** = the hard slot is named and every null is answered `none` (the black-box study's primary outcome).

Rungs: `none` always none; `c3` top-2 of ALL properties with latent ratio > 0.3; `sae_only` aligned properties with latent ratio > 0.225, no true-logit check; `verify_B` SAE ranking plus B true-logit texts per episode (base + topic swap + single flips; `verify_8` = 2 probes x 2 candidates x 1 base is the real budget); `verify_inf` all aligned candidates on all valid bases; `oracle` ground truth. Exact definitions: the script docstring.

A cell `x → y` is legacy scan → fixed scan; a single number means no change at two decimals.

## Sensitivity (not the fix): parent flips restricted too

`ladder_summary_six_both.json` (`--scan-both`): as the fixed scan, and in addition a parent property's flips are read only on bases where its child is off (a plain parent line added or removed). The fix as specified leaves the parent's all-32 ratio in place, which mixes two edits; this matters to `c3`, the one rung that ranks ALL properties. A cell `x → y` is fixed scan → this variant.
