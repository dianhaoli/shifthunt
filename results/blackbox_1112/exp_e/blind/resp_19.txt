A probe reaching high accuracy only shows that the label is linearly decodable from the activations. It doesn't show the model represents the concept you care about. With thousands of dimensions and confounded data, a probe can latch onto length, token identity, position, source dataset, or label imbalance and still score well.

## How to check

**1. Control tasks (selectivity).** Hewitt & Liang (2019) suggest assigning random labels that are consistent per input type (for example, per token identity) and training the same probe. Selectivity is the real-task accuracy minus the control-task accuracy. If a probe with high real accuracy also fits the random labels well, it has enough capacity to memorize, and its real-task score means little.

**2. Confound-only baselines.** List the surface features that might correlate with the label: length, specific tokens, punctuation, position, template, language, source dataset. Train probes on those features alone, and on raw token or bag-of-words features. If these get close to your probe's accuracy, the probe may be reading the confound.

**3. Residualization.** Project out the confound directions (or regress them out of the activations) and retrain. If accuracy collapses, the probe was mostly using them. Check this with a concrete measure: the cosine similarity between the probe direction and each confound direction.

**4. Decorrelated evaluation.** Build a test set where the concept and the confounds are independent: length-matched pairs, paraphrases, template swaps, held-out source datasets. Report accuracy stratified by confound value. A probe that drops sharply on the matched subset is tracking the confound.

**5. Causal tests.** Correlation is not enough.
- *Ablation:* project the probe direction out of the residual stream and measure whether the model's behavior on the concept changes. If it doesn't, the model may not use that direction.
- *Steering:* add the direction to activations on neutral inputs and check whether the output shifts in the expected way. If it shifts the output toward the confound instead, that's a problem.
- *Activation patching:* patch the direction between contrastive runs and see whether the output follows.

**6. Stability.** Vary the layer, seed, regularization strength, and train/test split. A real concept direction should be fairly stable. A confound-driven probe often isn't.

## How to fix

**Fix the data first.**
- Balance or match confounds across classes.
- Collect counterfactual pairs that differ only in the concept.
- Diversify sources and templates so the confound doesn't line up with the label.

**Remove the confound before probing.**
- Iterative nullspace projection (INLP) repeatedly trains linear classifiers for the confound and projects them out.
- Concept erasure methods such as LEACE remove linearly decodable information about a given attribute, which lets you test whether the concept is still decodable without the confound.
- Adversarial training: train the probe with an adversary that predicts the confound, and penalize the probe for succeeding.

**Constrain the probe.**
- Use strong L2 or L1 regularization, or fewer input dimensions (e.g., a PCA subspace).
- Select hyperparameters by selectivity, not raw accuracy. Prefer the simplest probe with high selectivity.

**Derive the direction from contrastive, matched data.** A difference-of-means direction computed on confound-matched pairs is less likely to pick up the confound than a discriminatively trained probe. Then validate it causally: it should change the model's output on the concept when steered, and ablating it should hurt concept-dependent behavior.

**Evaluate by worst group.** Report worst-group accuracy across confound strata (e.g., Group DRO-style evaluation), not just the average.

## What I'd report

For a probe claim, I'd want all of these: selectivity against a control task, performance of confound-only baselines, accuracy on a decorrelated held-out set, and at least one causal intervention (ablation or steering). A probe that passes only the first one is evidence the concept is decodable, not evidence the model uses it.
