A probe that predicts a concept well hasn't shown that it reads that concept. If the concept is correlated with something else in the training data (topic, length, token identity, position, formatting, the label distribution), a linear probe can exploit whichever feature is easiest to read out. The check is to separate the concept from its confounds and then test whether the probe's direction does causal work.

## How to check

**1. Find the confounds.** List what co-varies with your label in the dataset: surface features (length, punctuation, specific tokens), topic or domain, position in the sequence, source or template, and label balance. Then ask whether each one could linearly predict the label in the same activations.

**2. Probe for the confounds directly.** Train probes on the same activations to predict each confound. If a confound is decodable at high accuracy, a probe for the target could be picking it up. A useful comparison is whether the target probe's accuracy drops to the confound-only baseline after you control for the confound.

**3. Use controls.**
- *Control tasks / selectivity* (Hewitt & Liang, 2019): train the same probe on randomized labels with the same capacity. A high-capacity probe can memorize, so the gap between real-label and control-label accuracy is the meaningful number.
- *Shuffled-confound controls:* break the link between the target and the confound and see whether accuracy holds.

**4. Test on adversarial or matched data.**
- Build minimal pairs or counterfactuals that change the concept while holding confounds fixed (or the reverse).
- Test on out-of-distribution sets where the correlations are different or reversed. A probe that only works where the confound is present has learned the confound.
- Stratify accuracy by confound value. Large gaps between subgroups are a warning sign.

**5. Test causally, not just predictively.** This is the strongest check. Probes measure decodability, not use.
- *Ablation / amnesic probing* (Elazar et al., 2021): project the concept direction out of the residual stream and see whether the model's behavior on the concept changes. If behavior is unchanged, the model may not use that direction.
- *Activation steering:* add or subtract the probe direction and check whether outputs change as the concept predicts. If steering moves a confound (say, length) rather than the concept, the probe is tracking the confound.
- *Causal patching:* swap activations between counterfactual inputs and check whether the output follows the concept.

## How to fix it

**Data-side fixes**
- Balance or decorrelate the training data so the confound no longer predicts the label.
- Use counterfactual data augmentation: generate pairs that differ only in the concept.
- Train on multiple environments with different confound correlations and keep only features that are stable across them (the IRM-style idea).

**Probe-side fixes**
- Remove the confound subspace before probing. Iterative nullspace projection (INLP) or LEACE can erase linearly decodable confound information, so whatever the probe then finds is not that confound.
- Add the confound as a covariate or include confound-only features, so the concept direction must explain variance beyond the confound.
- Regularize toward sparse or low-norm solutions to discourage reliance on diffuse, confound-carrying directions.
- Prefer direction estimates that are more causally grounded, such as difference-of-means between contrastive sets, over discriminative probes that will grab any separable signal.

**Selection criteria**
- Choose the probe by causal efficacy (does steering or ablation work?) and by selectivity, not by raw accuracy on the original distribution.
- Report results on held-out, confound-controlled test sets, and state what the probe was validated against.

## A concrete example

Suppose you probe for "the model is about to refuse" and get 95% accuracy. You then find that refusals in your data are much longer and contain "I'm sorry." A confound probe for length predicts refusal at 85%. You build a matched set of long non-refusals and short refusals. Accuracy falls to 60%, and steering along the probe direction changes length rather than refusal. The probe was mostly reading length. The fix is to rebuild the dataset with length balanced, project out length, and re-validate with steering before trusting the direction.
