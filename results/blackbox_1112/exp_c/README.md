## Metric 1: captured fraction (ordinary probes, fixed scan)

Captured fraction = sum over the 32 stored bases of the oriented latent-visible change g.(F_flip - F_base) of the main cue's flip, divided by the sum of the oriented true logit change. 1 would mean the SAE latents carry the whole effect of the edit; the rest sits in the SAE error term. CI: 95% percentile bootstrap over bases, 10000 resamples, per source. The 32 bases are one stored draw per source. Pooled ratio of sums: numerators and denominators summed over sources (each multiplied by the cue's recorded sign), in raw probe-logit units and in topic units (each source's sums divided by its own true topic-swap effect).

## Metric 2: top-candidate accuracy (ordinary probes, fixed scan)

**The candidate set is privileged.** Candidates are the episode's 8 exactly label-aligned properties from the private answer file, each flipped in isolation with the generator's own renderer, and ranked by |latent ratio| (latent-visible effect over the latent-visible topic effect). An agent has to find these properties and write the edits itself, so this is an upper bound on what the SAE ranking gives an agent, not an agent result. Sign-aware = only candidates whose latent ratio has the sign of the property's alignment with the label are ranked.
